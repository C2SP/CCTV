# Accumulated SLH-DSA tests

This file provides [accumulated](https://words.filippo.io/accumulated/) random
SLH-DSA key generation and signature tests at various iteration counts.

## Key generation and signature tests

The vectors are generated by reading seeds from one instance of SHAKE128, and
writing the derived public key and the deterministic signature of an empty
message to another instance of SHAKE128.

```
s = SHAKE128()
a = SHAKE128()
for i in range(N):
    sk_seed = read(s, n)
    sk_prf = read(s, n)
    pk_seed = read(s, n)
    public_key = keygen(sk_seed, sk_prf, pk_seed)
    write(a, public_key)
    signature = sign_deterministic(seed, message="", context="")
    write(a, signature)
    if not verify(public_key, signature): error
result = read(a, 32)
```

This allows running a number of known-answer tests that would be impractical if
the results had to be stored in full.

100 iterations is suitable for rapid interactive tests. 10 000 iterations are
suitable for CI. Some iteration/algorithm pairs are not provided, due to high runtime costs.
